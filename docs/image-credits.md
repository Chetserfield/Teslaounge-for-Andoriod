# 차량 이미지 출처

`app/src/main/res/drawable-nodpi/lounge_vehicle.jpg`는 기존 TESLounge 홈페이지의 `public/assets/roadster-front.jpg`를 그대로 재사용했습니다. 이미지 파일 자체는 편집하지 않았고, 앱 화면에서 중앙을 기준으로 채워 표시합니다.

기존 홈페이지의 출처 기록:
- Tesla Roadster 페이지: https://www.tesla.com/roadster
- 원본 주소: https://digitalassets.tesla.com/tesla-contents/image/upload/f_auto,q_auto/Roadster-08-End-Desktop.jpg
- 기존 자료 기록일: 2026-10-29

이 이미지는 브랜드 분위기를 보여주는 비주얼입니다. 사용자가 연결한 차량, 선택한 차종, 앱 지원 차종을 뜻하지 않습니다. 앱에서도 이 점을 표시합니다.

이미지 권리는 원 권리자에게 있습니다. 이 문서는 기존 출처 기록을 보존하며 상업적 이용 허가를 주장하지 않습니다.
