# 카카오 가입 진입 구현 계획

사용자가 권장안을 앱에 적용하도록 위임함. 공개 읽기 + 참여 시 카카오 가입, Supabase 인증을 목표로 한다.

현재 백엔드와 카카오 개발자 앱이 없으므로 이번 구현은 로그인 진입 UX와 게스트 참여 제한이다. 인증 성공을 흉내 내거나 로컬 상태를 회원 권한으로 사용하지 않는다. 기존 로컬 기능은 명시적인 기기 체험으로 보존한다.

1. MainActivity: 로그인 Dialog 진입, MY 계정 상태, 글/댓글/공감 게이트. 취소 시 원래 화면과 입력 보존.
2. LoginSheet: 검정 배경, 노란 카카오 버튼, 둘러보기, 구분된 기기 체험. 카카오 버튼은 미설정 이유를 알리고 실제 로그인 처리하지 않음.
3. AppFlowTest: 게스트 쓰기 차단, 카카오 미설정 후 게스트 유지, 취소 복귀, 체험 진입/종료 및 기존 기능 회귀.
4. 빌드/lint/에뮬레이터 테스트 후 APK·미리보기 갱신.

## 다음 실제 인증 연결
사용자 소유 Supabase 및 Kakao 프로젝트 설정 후 시스템 브라우저 OAuth + PKCE, 제한된 앱 복귀 URI, 서버 검증 세션, 서버 RLS를 함께 구현한다. 비밀키는 APK에 넣지 않는다. 프로필 완료 전 약관 동의 및 서비스 닉네임/유형을 받는다. 앱 회원 ID와 카카오 identity 연결, 세션 만료/취소/재시도, 로그아웃, 회원 탈퇴와 카카오 연결 해제를 검증한다. 현재 로컬 글은 자동 업로드하지 않는다. 인증/탈퇴 완료 UI는 실제 서버 동작이 준비된 뒤 제공한다.

## 검토 초점
카카오 버튼 후 허위 로그인 금지, 취소 시 입력 보존, 체험 상태와 회원 상태 구분, 앱 재시작 시 체험 권한 초기화, 기존 저장 데이터 보존.
