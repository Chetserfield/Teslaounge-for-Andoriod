# 공유 서버 구현 계획

사용자 요청: 여러 휴대폰에서 같은 커뮤니티를 사용하도록 서버 구축.
선택: 기존 합의한 Supabase Auth + PostgreSQL + REST API. Kakao OAuth PKCE, Android Keystore로 세션 보호. 미설정 빌드는 기존 로컬 체험 유지.

1. PostgreSQL migration: 공개 프로필, 게시글/댓글/공감, 승인된 케어 업체 및 광고. 작성자만 변경하고 관리자 전용 승인/숨김 필드는 일반 회원이 변경 불가.
2. 실제 PostgreSQL 호환 엔진으로 서로 다른 사용자/게스트의 RLS 권한을 검증. 배포 후 REST 검증 스크립트도 제공.
3. Android: 빌드 설정으로 서버 연결, 브라우저 Kakao 인증과 PKCE callback, 암호화 세션 저장/갱신/로그아웃. 공유 커뮤니티 화면은 로컬 예시와 분리.
4. 배포/키 설정 가이드 및 APK 빌드·회귀 테스트. 사용자 소유 클라우드 계정이 없으면 배포가 완료됐다고 표시하지 않음.

제외: 결제, 실제 예약, 차량 제어, 자동 로컬 데이터 이전. 공개 운영 전 약관/개인정보 정책, 신고/차단과 운영 담당자 설정 필요. 이번 서버는 소규모 비공개 테스트용 MVP.
