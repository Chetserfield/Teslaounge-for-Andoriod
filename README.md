# TESLounge Android 0.2

기존 v0.1 Java 네이티브 앱을 복원하고, 서비스 기획안 v0.3의 사용자 유형별 메뉴를 반영한 오프라인 개발본입니다. 개발용 APK 빌드와 서명 검증을 완료했습니다. 에뮬레이터 검증 결과는 아래에 기록합니다.

## 이번 변경
- MY에서 관심자 / 예비 오너 / 오너 선택 및 기기 내 저장
- 유형별 홈 안내와 5개 하단 탭
- 예비 오너와 오너의 커뮤니티에서 인도 체크리스트 진입
- 뉴스, TSLA, 서비스, 내 차의 미연결 안내 화면
- 기존 글쓰기, 검색, 댓글, 공감, 글 삭제, 체크리스트, 닉네임 기능 유지

사용자 유형은 화면 구성에만 사용합니다. 인증과 서버 권한은 아직 없습니다. 모든 작성 내용은 기기에만 저장되고 다른 사용자에게 공유되지 않습니다. 뉴스·주가·예약·차량 데이터는 연동하지 않았습니다.

## 빌드 환경
이 작업 폴더의 상위 `.android-tools/`에 JDK 17, Android SDK 35, Build Tools 34.0.0, Gradle 8.9를 설치했습니다. Gradle wrapper와 공식 배포 SHA-256 검증 설정을 포함했습니다.

현재 Mac에서:

```sh
bash scripts/build-local.sh
```

다른 컴퓨터에서는 JDK 17과 SDK 35를 준비하고 `ANDROID_HOME`을 설정하거나 Android Studio에서 SDK 위치를 선택한 뒤 실행합니다.

```sh
./gradlew assembleDebug lintDebug
```

APK 경로: `app/build/outputs/apk/debug/app-debug.apk`. 개발용 디버그 서명이며 스토어 제출용 릴리스 APK는 아닙니다.

테스트 전용 에뮬레이터를 실행한 상태에서:

```sh
bash scripts/build-local.sh connectedDebugAndroidTest
```

이 테스트는 테스트 앱의 로컬 데이터를 초기화하므로 개인 데이터가 있는 실기기에는 실행하지 마세요.

## 검증 결과 · 2026-11-01
- 앱 및 테스트 APK 컴파일·패키징 성공
- Android lint: 오류 0개, 경고 5개 (테스트 라이브러리 최신 버전 안내 3개, 백업 규칙 안내, 문자열 국제화 안내)
- Android 8.0에서 지원하지 않는 테마 속성을 버전별 리소스로 분리
- APK v2 서명 검증 통과
- Android 15 / API 35 / Pixel 6 가상 기기: 자동 테스트 5개 통과
- 홈·게시판 세로 화면, 게시판 가로 화면, 글자 크기 1.3배 홈 화면 확인
- 실제 휴대폰 검증: 미실행

## 검증할 주요 흐름
1. MY에서 세 유형을 각각 저장하고 홈 안내와 하단 메뉴가 바뀌는지 확인
2. 앱 재시작 후 유형·닉네임·관심 모델 유지 확인
3. 글 작성 → 검색 → 상세 → 공감 → 댓글 → 삭제 확인
4. 인도 체크리스트 저장 및 재시작 후 유지 확인
5. 모든 탭과 뒤로가기, 좁은 화면, 큰 글자, 화면 회전 확인
6. 뉴스·주식·예약·차량 연결이 준비 중으로 표시되는지 확인
